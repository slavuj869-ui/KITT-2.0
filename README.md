# KITT 2.0

Separat Android-projekt. Referensdesign: svart/röd KITT-panel, holografiskt ansikte, tvåvägsskanner, sex ljudstaplar och responsiv layout.

Bygg: GitHub Actions → Build KITT 2.0 APK → artifact `KITT-2.0-APK`.

Första bygget är en teknisk grundversion. Den exakta hologrambilden från konceptet återstår att importera.
